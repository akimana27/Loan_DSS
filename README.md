# LoanSight — Loan Approval Risk Analysis DSS

> *Empowering smarter lending decisions through the power of data and machine learning.*

## Dataset

The dataset contains real-world inspired loan application records with features including:

- **Demographics** — Age, education level, city
- **Employment** — Employment status, years of experience  
- **Financials** — Annual income, credit score, loan amount
- **Target** — Loan approval status (Approved / Rejected)

## Problem Statement

Every day, financial institutions process thousands of loan applications — a process that is:

- **Time-consuming** :manual reviews take days or weeks
- **Inconsistent** : decisions vary between reviewers
-  **Risky**:  poor decisions lead to financial losses
- **Complex**: multiple variables must be considered simultaneously

**LoanDSS** solves this by combining machine learning with an intuitive interface to deliver fast, consistent, and data-driven loan risk assessments transforming how lending decisions are made.

## Key Features
 **Single Applicant Analysis** : Instantly assess risk for individual loan applicants 
**Batch Processing** : Analyze hundreds of applications at once 
**EDA Explorer** : Uncover hidden patterns in loan data interactively 
**Model Insights** : Understand what drives approval and rejection 
**Overview Dashboard** :Bird's-eye view of your loan portfolio
